These are ES-DE's own Android configuration files, bundled so Pegasus X can read
an ES-DE setup (its systems, emulators and launch commands). They're taken
unchanged from ES-DE (resources/systems/android/) and are under ES-DE's MIT
license, see LICENSE-ES-DE.

To update them, replace both XML files with the newer ones from ES-DE.
Users can still override any system or emulator with their own
ES-DE/custom_systems/es_systems.xml and es_find_rules.xml.
